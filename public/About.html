Overview

Agentic Timetable upgrades the original easy-timetable parser into an intelligent university schedule platform. It parses raw Excel timetables into structured fields (course, day, time, lecturer, unit code, unit name, venue, and delivery mode), refreshes live without restarting the server, and provides a tool-calling Timetable Agent alongside clash detection, free-room search, and .ics calendar export.

Key Capabilities

  • Smart Excel Parsing: Extracts lecturer, unit code, unit name, venue, and delivery mode (in-person, online, self-paced) across all workbook sheets.
  • Tool-Calling Timetable Agent: Answers natural-language questions (e.g. "Find free rooms on Tuesday 0800-1100", "Audit timetable clashes") with optional Gemini/OpenAI API keys or zero-key local planning.
  • Free Room & Clash Auditor: Finds unoccupied physical rooms and detects personal or system-wide lecturer/venue conflicts.
  • Personal Schedule & .ics Export: Save classes into a personal week view with automatic clash alerts and export to Google/Outlook/Apple Calendar.

REST API Endpoints

  • GET /api/health — Server status & loaded dataset info
  • GET /api/stats — Course, class, lecturer, venue, and system clash statistics
  • GET /api/courses?q=&program=&year=&semester= — List matching courses
  • GET /api/search?q=&course=&day=&time=&lecturer=&unit=&venue=&mode= — Multi-facet search
  • GET /api/free-rooms?day=&time= — Available physical classrooms
  • POST /api/clashes — Check conflicts for { items } or { mode: "system" }
  • POST /api/agent/chat — Natural-language tool-calling assistant
  • POST /api/upload (or POST /file) — Upload & live-reload Excel timetable
  • POST /api/export/ics — Export selected slots or course as .ics
